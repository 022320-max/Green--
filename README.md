# Green Wedge — 비인간권리 충돌 시뮬레이션

인간의 주거·의료 접근권과 야생동물의 서식권이 충돌하는 가상의 사례를 선택형으로 탐구하는 정적 웹사이트입니다.

## GitHub Pages로 공개하기
1. GitHub에 로그인하고 새 저장소(repository)를 만듭니다. 예: `green-wedge-simulation`
2. 저장소를 `Public`으로 설정하고 `index.html` 파일을 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 설정하고 **Save**를 누릅니다.
6. 잠시 후 Pages 화면에 표시되는 사이트 주소로 접속합니다.

## 구성
- 첫 번째 선택: 공사 즉시 진행 / 전면 중단 / 구간 조정·생태통로 / 공동 심의
- 선택별 결과와 세 가지 가상 지표
- 후속 갈등과 두 번째 선택
- 토론 질문: 권리의 범위, 대표성, 비용 부담, 사전 예방

## 수정
사이트의 글·선택지·결과는 `index.html`에서 수정할 수 있습니다. 점수는 학습용 가상값이며 실제 데이터를 나타내지 않습니다.
